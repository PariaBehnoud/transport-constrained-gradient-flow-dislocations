# Transport-Constrained Gradient-Flow Formulation for Continuum Dislocation Dynamics

This repository contains the numerical Python scripts accompanying the manuscript

**A Transport-Constrained Gradient-Flow Formulation for Continuum Dislocation Dynamics**

by **Paria Behnoud, Anthony Rollett, Carlos Mora-Corral, Jaroslaw Knap, and Kaushik Dayal**.

The codes reproduce the reduced collective-coordinate calculations for the opposite-sign dislocation-pair examples presented in Section 6 of the manuscript.

## Repository contents

### `regime_I_opposite_pair.py`

Computes the Regime I dynamics of an opposite-sign dislocation pair and compares the elastic-only trajectory with the trajectory generated by the total reduced energy.

### `regime_II_applied_stress.py`

Computes the Regime II response under a superposed uniform resolved shear stress, including the energy landscape, force balance, and stability boundaries.

### `regime_II_fold_values.py`

Computes the lower and upper fold thresholds for the applied-stress problem in Regime II.

## Requirements

Python 3 with:

- NumPy
- SciPy
- Matplotlib

Install the required packages using:

`python -m pip install -r requirements.txt`

## Running the codes

Regime I:

`python regime_I_opposite_pair.py`

Regime II with applied stress:

`python regime_II_applied_stress.py`

Fold-threshold calculation:

`python regime_II_fold_values.py`

## Scope

These scripts implement the reduced collective-coordinate examples presented in Section 6 of the manuscript. They are not a full-field implementation of the complete transport-constrained continuum dislocation model.
